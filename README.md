# 镜投

让 iPhone 和 iPad 通过无线「屏幕镜像」或 USB 数据线，把画面投到 Mac。

**镜投与 [WindowPaste（窗贴）](https://github.com/Terry1238832/WindowPaste) 已在当前源码中合并**：投屏继续使用主窗口，截图、快捷键与粘贴放在「辅助功能」的独立窗口。公开下载的 1.1.1 安装包仍是合并前版本。

官网：[terry1238832.github.io/AirMirror](https://terry1238832.github.io/AirMirror/)

## 安装

1. 到 [Releases](https://github.com/Terry1238832/AirMirror/releases/tag/v1.1.1) 下载 `AirMirror-1.1.1.dmg`，或从官网下载
2. 把「镜投」拖进「应用程序」
3. 第一次打开如果被系统拦住：按住 Control 点图标，选择「打开」

需要 Apple 芯片的 Mac，macOS 14 或更新。无线投屏时，手机和 Mac 要在同一个可以互相发现的局域网里。

## 1.1.1 更新

设置面板淡入并轻弹展开，连接方式切换和高级选项折叠更加连贯。开始、结束投屏及画面旋转时，窗口会平滑调整尺寸；手动缩放与比例滑块仍保持即时响应。动效会跟随 macOS 的「减少动态效果」设置自动收敛。

## 无线投屏

1. 在镜投中选择「无线投屏」。
2. 将 iPhone / iPad 和 Mac 连接到可以互相发现的同一局域网。
3. 在设备控制中心点「屏幕镜像」，选择镜投的接收端显示名。

当前源码默认使用这台 Mac 的设备名称；已有自定义名称会保留。在设置中清空显示名可恢复默认，下次打开应用时会读取 Mac 的最新设备名称。公开下载的 v1.1.1 默认名仍为「镜投」。

右上角「?」内提供两种图标的版本对照。iOS 11 及以后和 iPadOS 使用双矩形「屏幕镜像」；早期 iOS 的 AirPlay / 镜像入口使用屏幕加三角图标。在 iOS / iPadOS 18、26、27 中，屏幕加三角通常用于播放 App 内的视频，整屏投屏应选择双矩形。[Apple 图标与操作说明](https://support.apple.com/zh-cn/102661)。

教程可通过右上角关闭按钮、按 `Esc` 或点击投屏窗口的空白处收起。

## USB 有线投屏

学校 Wi-Fi 开启设备隔离、局域网无法互通时，可以使用有线模式：

1. 在镜投中选择「USB 有线」。
2. 使用支持数据传输的 USB-C 或 Lightning 线连接 iPad / iPhone 和 Mac。
3. 解锁设备，确认「信任此电脑」，并允许镜投访问相机，画面将自动出现。

macOS 把 USB 设备屏幕归为相机采集源，因此需要相机权限。有线模式无需同一 Wi-Fi，也无需在 iPad 上打开「屏幕镜像」。插拔后会自动重新检测，可在设备列表中手动选择。若没有显示设备，请确认线缆支持传输数据，并关闭其他正在采集该设备的应用。

在设置中开启「播放设备声音」可以接收设备音频；此选项需要麦克风权限，默认关闭。拒绝音频权限不会阻止画面投屏。受保护的视频内容仍可能无法显示。

菜单栏的「连接」可直接切换无线 / USB，调整画质、帧率和配对码，或选择有线设备、重新检测与控制设备声音，并开始、停止或重新连接。显示名仍在设置窗口修改。「画面」区直接提供比例开关、宽窄滑块和重置，不再折叠在高级设置内。

有线模式使用 macOS 的 AVFoundation / CoreMediaIO 接口，不依赖 UxPlay。

## 辅助功能：窗贴（当前源码）

在「辅助功能 → 窗贴 · 截图与粘贴」打开独立窗口。等待页、投屏画面右上角和菜单栏均有入口。主窗口的连接教程收在右上角「?」中，无线与 USB 模式使用分开的按钮。设置使用独立的纵向窗口，也可从应用菜单或按 `⌘,` 打开。窗贴与投屏窗口独立，关闭窗贴不会中断投屏；镜投运行且窗贴快捷键已启用时，关闭窗贴窗口后快捷键仍然有效。

- 默认截取镜投正在接收的设备画面，截图不包含窗贴面板或投屏控制按钮；也可以选择其他正在运行的应用及指定窗口，并预览目标。
- GitHub 版将光标放在要插入图片的应用中，按默认快捷键 `⌘·` 截取并粘贴。商店版的快捷键截取并复制，由用户手动 `⌘V` 粘贴。可录制新快捷键，冲突时会提示；窗口内的「复制截图」在两渠道均只复制。
- macOS 14.4 及更新系统可以直接读取投屏帧，无需屏幕录制权限；截取其他应用窗口或使用较早的 macOS 14 系统时，需要为「镜投」开启屏幕录制权限。自动粘贴需要「辅助功能」权限，未开启时仍可复制截图。
- GitHub 版的「自动回车」默认关闭，可按需打开；截图期间若目标应用切换，会保留截图在剪贴板而不自动粘贴。商店版不包含自动粘贴、辅助功能授权及自动回车。
- 登录启动选项控制镜投整体。独立版窗贴的权限与快捷键不会自动迁移；若独立版仍占用快捷键，可以退出它或在镜投内另设快捷键。

此功能由 [WindowPaste](https://github.com/Terry1238832/WindowPaste/tree/d8f6bcb86a419b410518264798f5931b2d3344d3) 整合而来，保留 [MIT 许可证](AirMirror/WindowPaste/WindowPaste-LICENSE.txt)。当前源码的辅助功能尚未包含在已发布的 1.1.1 安装包中。

## Mac App Store 准备情况

计划在 Mac App Store 使用名称 **镜投:专业屏幕镜像软件**，应用内保留「镜投」短名称。

2026-11-14 已建立真正启用沙盒的商店配置，完成独立 helper、容器内视频通道、统一团队签名及 macOS 14+ 无线运行时打包。真实 USB 投屏、沙盒内截图复制及 HEVC 2882 × 2160 无线接收已验证，**当前仍未完成完整提交验收**。详细证据和剩余的实机、分发签名、账号与许可核查见 [上架预检报告](docs/MAC_APP_STORE_REVIEW.md)。这不是 Apple 审核结果。

- GitHub 版在等待页、设置和窗贴窗口底部显示本仓库链接，并保留 GitHub 手动检查更新。
- 商店渠道通过 `APP_STORE` 编译条件移除仓库入口和 GitHub 更新代码，保留隐私说明与开源许可；窗贴改为截图复制后手动粘贴。使用 `AirMirrorStore` scheme 构建，流程见 [商店构建说明](docs/APP_STORE_BUILD.md)。
- [隐私说明](https://terry1238832.github.io/AirMirror/privacy.html) 同时以本地文本随应用打包，可离线阅读。隐私清单描述当前第一方代码，不代表所有运行时依赖已核验完毕。

## 从源码编译

需要 Xcode、Homebrew，以及 `cmake`、`openssl@3`、`gstreamer`、`pkgconf`、`libplist`。

```bash
./release.sh
```

会生成 `dist/镜投-1.1.1.dmg`（发布到 GitHub 时文件名为 `AirMirror-1.1.1.dmg`）。无线画面接收使用 [UxPlay](https://github.com/FDH2/UxPlay) `59f65c8`，改动在 `scripts/patches/`。UxPlay 以 GPL-3.0 发布。
