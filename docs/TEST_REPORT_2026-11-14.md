# 镜投本轮功能测试与剩余结论

日期：2026-11-14。基础版本 `b2c8bce`；本轮增加窗贴语言刷新和 USB 启动权限处理修复。测试主机为 Apple 芯片 Mac、macOS 27.2；真实 iPad 通过数据线连接。商店测试标识为 `com.liangyu.airmirror.mas`。

**本轮没有替换无线引擎。** 原生系统「屏幕镜像」连接方式保留，接收核心仍为现有 UxPlay。替代候选、接入条件和结论见 [无线接收替换评估](app-store/RECEIVER-REPLACEMENT-EVALUATION.md)。下列结果属于当前镜投，不属于不存在的新 SDK 构建。

## 真实设备与界面观察

| 项目 | 本轮观察结果 |
| --- | --- |
| USB 显示 | 实际收到并显示 iPad 画面，设置显示 1600×1200 |
| 停止与重连 | 停止后画面尺寸清空；重新开始及「重新连接」能恢复真实画面 |
| 模式切换 | USB → 无线时接收端能启动且广播可被发现；再切回 USB 可恢复画面 |
| 真实帧复制 | 窗贴目标为 1600×1200 原始设备画面，按钮返回复制成功及手动 ⌘V 提示；关闭窗贴后投屏继续 |
| 无画面保护 | 没有视频时提示先连接设备，没有报出复制成功；自动回归另验证断线后不返回旧帧 |
| 可选 USB 音频 | 开关可开启和关闭，画面保持；最终恢复关闭。没有播放可辨识设备音源，声音内容、延迟及音画同步未完成验收 |
| 语言 | USB 接收中切换英语，画面保持；窗贴目标下拉框旧语言缓存被复现并修复，重新打开后目标为英文，旧提示清除；最终恢复跟随系统 |
| 商店入口 | 设置、主页面及窗贴仅有隐私/许可入口；无仓库按钮、外部更新、自动粘贴或自动回车控件 |
| 退出与重开 | 修复后连续 3 次退出再打开，USB 均自动发现并恢复实际画面；第 3 次再次核对 1600×1200，并成功复制真实帧 |

复制后的系统「预览」交叉打开未完成：应用选择出现界面控制超时。窗贴已报告复制成功，PNG/TIFF 编码与读取另由自动回归覆盖；这不等于已验证所有外部应用的粘贴兼容性。真实 iPad 截图、设备标识及原始诊断 JSON 均未加入仓库。

## 本轮修复

- 窗贴目标原生 Picker 使用语言作为刷新标识，避免复用旧语言标题；切换语言时清除旧语言状态提示，截图目标和快捷键偏好不变。
- USB 启动先解析相机授权，再开启设备发现。未授权时可以直接请求；拒绝或受限时报告权限问题，不再只依赖「先发现设备、再检查权限」的路径。异步结果仍检查当前会话代次，停止后的回调不会重新启动。

测试中曾出现应用重启后等待设备的状态。「系统信息」USB 列表当时为空，但底层 USB 注册表能找到 iPad，CoreDevice 显示有线连接且已配对；锁状态查询为 `passcodeRequired=false`。独立公开 API 探针也能枚举到 muxed 设备，因此未将该异常认定为设备拔线。

调整相机授权与枚举顺序后完成了上述 3 次冷启动显示及再次截图。诊断过程中使用过独立枚举探针；这些结果证明当前主机恢复，不替代无探针的干净系统和权限矩阵验收，也未证明覆盖所有 macOS 版本的同类问题。

## 尚未完成的验收

1. **无线原生镜像的新连接和真实画面**：本轮已测接收端启动与 Bonjour 广播；用户无法在 iPad 上点击发起新连接，所以本轮没有新的无线画面/清晰度/长时间连接证据。此前用户确认的 HEVC 2882×2160 记录仍是历史证据。
2. **完整设备矩阵**：真实旋转、锁屏、物理拔插、受保护内容限制、长时间动态场景、可辨识音源及音画同步。合成帧旋转和模式切换测试不能冒充这些实机结果。
3. **权限及系统矩阵**：首次允许/拒绝/撤销和重新授予相机、麦克风、屏幕录制；真实全局快捷键冲突及登录启动；无 Homebrew 的干净 macOS 14。没有为测试擅自重置已有授权或启用登录启动。
4. **商店分发**：新接收实现的来源/许可仍未关闭，现有 UxPlay/GPL 与 LGPL 的源码和分发方案仍待确认；还需分发证书/描述文件、Apple Validate App、加密出口申报、最终截图和 App Store Connect 资料。

## 下一步

在保持 iPad 原生「屏幕镜像」的前提下，先取得一个可交付的原生 arm64 SDK 及明确再分发材料，或完成现有实现的授权方案确认，再安排接入。厂商询问稿见 [SDK 询问稿](app-store/SDK-INQUIRY-DRAFT.md)。未向厂商发信、购买许可或接受合同。

当前结果可以作为功能和构建检查的阶段验收，**仍不能称为完整实机矩阵全部通过或可直接送审**。
