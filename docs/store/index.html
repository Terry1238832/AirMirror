隐私说明English

镜投商店版包含 Mac 接收端与 iPad 屏幕共享端。无线共享使用加密局域网连接；Mac 另提供 USB 有线投屏和独立窗贴截图复制。

无线连接

  1. 两端打开镜投，连接可以互通的同一 Wi-Fi。
  2. Mac 点“配对 iPad”，iPad 扫码或手工输入配对串。
  3. 核对两端数字一致后，在 Mac 允许连接。
  4. iPad 点“共享屏幕”，并在系统界面确认。你可以随时停止。

没有发现 Mac 或连接不上

检查两端的局域网权限、接收端是否开启，以及 Wi-Fi 是否允许设备互访。访客网络或学校的 AP 隔离可能阻止无线连接；USB 模式不需要同一 Wi-Fi。

USB 和声音

使用支持数据传输的线缆，解锁 iPhone 或 iPad 并信任 Mac。macOS 相机权限用于读取 USB 设备屏幕。只有启用设备声音才需要音频输入权限；无线首版只传视频。

窗贴

从辅助功能打开独立窗贴窗口，选择目标、截取并复制，再手动粘贴。截取其他应用窗口需要屏幕录制权限。
