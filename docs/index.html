HOW IT WORKS

三步，画面就在这个窗口里。

01

打开镜投

它会在局域网里广播。手机和 Mac 要在同一个 Wi-Fi。

02

点屏幕镜像

在 iPhone 或 iPad 的控制中心点「屏幕镜像」，选择镜投。

03

看这一个窗口

等待页和投屏画面在同一个窗口。全屏时保持手机原来的比例。

FAQ

下载之前。

支持哪些设备？

接收端是 Apple 芯片的 Mac，系统 macOS 14 或更新。手机和平板是 iPhone、iPad，用系统自带的屏幕镜像，不需要额外 App。

搜不到镜投？

手机和 Mac 要在同一个局域网。公司或酒店的隔离 Wi-Fi 经常会挡住设备互相发现，换一个可以互通的网络再试。

画面会不会被拉变形？

窗口会锁住设备比例。全屏时四周留黑边，画面本身按原来的宽高显示。

为什么第一次打开要手动允许？

安装包没有经过 Apple 公证。这只影响第一次打开，按住 Control 点「打开」即可。
