HOW IT WORKS

无线投屏，三步连接。

01

选择无线投屏

打开镜投，选择「无线投屏」。手机和 Mac 连接到可以互相发现的同一局域网。

02

点屏幕镜像

在 iPhone 或 iPad 的控制中心点「屏幕镜像」，选择镜投。

03

看这一个窗口

等待页和投屏画面在同一个窗口，切换时自然过渡。窗口平滑调整尺寸，全屏时保持设备原来的比例。

USB MIRRORING

校园网不互通，就插线。

  1. 01

    选择 USB 有线

    在镜投中切到「USB 有线」，用支持数据传输的 USB-C 或 Lightning 线连接设备与 Mac。

  2. 02

    解锁并信任电脑

    解锁 iPhone 或 iPad，确认「信任此电脑」，按提示输入设备密码。

  3. 03

    允许访问，自动投屏

    允许镜投访问相机后，画面自动出现。无需同一 Wi-Fi，也无需打开「屏幕镜像」。

WINDOWPASTE INTEGRATION

投屏和窗贴，合在一起。

当前开发源码已合并 WindowPaste：在镜投的「辅助功能」中打开独立窗贴窗口，截取投屏画面或指定应用窗口，再用快捷键复制、粘贴。关闭窗贴窗口，投屏继续运行。

此合并尚未包含在下方的 1.1.1 安装包中。查看合并源码与说明

FAQ

下载之前。

支持哪些设备？

接收端是 Apple 芯片的 Mac，系统 macOS 14 或更新。iPhone 和 iPad 可以使用无线屏幕镜像，也可以用 USB 数据线连接，无需在设备上额外安装 App。

学校 Wi-Fi 搜不到镜投？

无线投屏需要设备能在局域网中互相发现。学校、公司或酒店的隔离 Wi-Fi 可能会阻止连接，可以切换到「USB 有线」，直接用数据线投屏。

USB 为什么需要相机权限？

macOS 将数据线连接的 iPhone / iPad 屏幕作为采集源，归入相机权限。请在「隐私与安全性 → 相机」中允许镜投。有线模式接收的是设备屏幕。

插线后没有画面？

请确认线缆支持数据传输，解锁 iPhone / iPad 并信任这台 Mac，再点「重新检测设备」。如果其他应用正在采集同一设备，请先关闭它们。

有线投屏可以播放设备声音吗？

可以。在设置中开启「播放设备声音」，并允许麦克风权限，用于接收数据线传来的设备音频。此选项默认关闭；拒绝音频权限不会阻止画面投屏。

可以减少界面动画吗？

可以。镜投会跟随 macOS 的「减少动态效果」设置，收敛设置面板、内容切换和窗口调整的动效。

画面会不会被拉变形？

窗口会锁住设备比例。全屏时四周留黑边，画面本身按原来的宽高显示。

为什么第一次打开要手动允许？

安装包没有经过 Apple 公证。这只影响第一次打开，按住 Control 点「打开」即可。
