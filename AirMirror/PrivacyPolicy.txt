镜投隐私说明
更新日期：2026 年 11 月 14 日
适用范围：镜投及其内置的窗贴辅助功能。
开发者：粮宇。

本地处理
镜投在 Mac 上接收、显示来自 iPhone / iPad 的画面及可选音频。窗贴按你的操作读取投屏帧，或在获得屏幕录制权限后预览、截取指定应用窗口。画面、音频和窗口预览用于这些本地功能；镜投不会将它们上传给开发者，也不包含广告、分析或第三方 AI 服务。

剪贴板与粘贴
截图会写入 macOS 系统剪贴板，替换原有剪贴板内容。系统通用剪贴板或你安装的剪贴板管理软件可能按其自身设置同步、保存该内容。GitHub 版可在你授予辅助功能权限后，按快捷键将截图粘贴到当前前台应用；自动回车默认关闭，启用后可能触发接收应用发送。接收应用对图片的保存、同步和发送受其自身隐私规则控制。你可只使用「复制截图」，再决定在哪里手动粘贴。

权限与控制
局域网权限用于无线设备发现和连接；相机权限用于 USB 设备屏幕采集；麦克风权限仅在你开启有线设备声音时请求。屏幕录制用于其他应用窗口的预览、截图，以及较早 macOS 14 系统的投屏窗口截图回退；较新系统可直接读取镜投自身画面。辅助功能权限用于 GitHub 版跨应用自动粘贴。你可在 macOS「系统设置 → 隐私与安全性」撤销权限，停用快捷键，关闭自动回车，或退出应用停止接收和截图。登录启动由你主动开启，可随时在应用或系统登录项设置中关闭。

本地保存与删除
应用会在本机保存自定义显示名、语言、连接方式、设备选择、画质、快捷键、所选应用和窗口标题等偏好；还会保存无线引擎配置及 GStreamer 缓存。截图和窗口预览仅保存在运行时内存及剪贴板，镜投没有截图历史库或录屏文件保存功能。停止投屏或退出后会释放运行时画面；退出不会自动清空系统剪贴板，复制其他内容可替换其中截图。本机诊断信息由 macOS 日志系统按其规则管理，可能包含连接状态和错误；无线引擎原始输出和引擎路径使用系统日志隐私遮蔽。应用没有开发者后台账户或云端截图库。删除应用不会保证偏好、缓存、系统日志、剪贴板工具或接收应用中的数据同时删除。

网络访问
无线投屏通过你所连接的本地网络与设备通信。接收端显示名默认包含应用名称和 Mac 设备名称，并通过 Bonjour 向局域网内设备广播；你可在设置中自定义名称。GitHub 版仅在你点击「检查更新」时访问 GitHub 发布接口，发送正常联网所需的技术信息（如 IP 地址、请求时间和 HTTP 标头），不随该请求发送投屏内容、截图、窗口标题或设置。商店版使用 Mac App Store 更新，不包含该检查入口。打开外部网页时，浏览器与网站可能按各自规则处理访问数据。镜投不将这些请求数据用于广告或跟踪。

反馈与隐私请求
可通过镜投下载页面列出的项目支持渠道联系开发者。你主动提交的反馈、日志或截图会按对应平台规则保存；请先去除私人信息。公开反馈无需附带截图、设备名称或完整日志。开发者无法代为删除其他应用、剪贴板工具或操作系统持有的数据；请在对应服务中处理。

说明更新
如后续功能改变数据处理方式，本说明会随版本更新。此说明不代表应用已通过 Mac App Store 审核。
